## 正文与强调

直接写中文段落。段落之间空一行。使用 **加粗** 强调结论，使用 `行内代码` 标记函数或变量。

> 引用一段值得留下来的话。

## 代码片段

在代码围栏后写语言名，就会显示对应的语法高亮。

```typescript
function greet(name: string): string {
  return `你好，${name}`;
}

console.log(greet('世界'));
```

## 列表与表格

- 问题是什么？
- 尝试过哪些方法？
- 得到了什么结论？

| 记录内容 | 用途 |
| --- | --- |
| 背景 | 说明为什么要解决这个问题 |
| 过程 | 留下尝试和判断的依据 |
| 结论 | 总结收获与下一步 |

## 链接与图片

[回到博客首页](../../)

图片建议放到 `content/images/`，在 Markdown 中使用相对路径，例如：

```markdown
![图片说明](../images/your-image.png)
```

这里展示的是写法，添加真实图片后再使用。不要在公开仓库中提交不希望公开的内容。
